# หน้าตา Light / Dark

UI รุ่นปรับแต่งนี้ใช้แอป PySide6 เดิม เปิดด้วย `RGBMoCap.cmd` แล้วเลือก **Light** หรือ **Dark** ที่มุมขวาบน

- **Dark**: พื้นดำและเทากลาง ปุ่มหลักสีน้ำเงิน ไม่มีพื้นม่วง
- **Light**: พื้นเทาเงิน แผงสีอ่อน และสีข้อความที่ปรับตามธีม
- วิดีโอ, viewport และ timeline สลับพื้นตามธีมทั้งหมด Light ใช้พื้นสว่างและเส้นกริดสีเทา ส่วนสี actor/contact/XYZ คงความหมายเดิม
- Timeline แยกรางชื่อแทร็ก เส้นแบ่งแถว และพื้นสลับเฉด; คลิปที่มีข้อมูลเป็นแถบมุมมน โดยตำแหน่ง trim/contact และการลากแก้ไขยังเหมือนเดิม
- ฟอนต์อังกฤษ/ตัวเลขใช้ **Manrope** และภาษาไทยใช้ **Noto Sans Thai**; ฟอนต์พร้อมใบอนุญาตอยู่ใน `assets/fonts/` ไม่ต้องติดตั้งลง Windows
- **Open video**, **Model Manager**, **Export** อยู่บน toolbar; ปุ่ม **Reconstruct 3D** และการยกเลิกงานอยู่ด้านล่าง inspector และไม่เลื่อนหายไปกับ settings
- controls ของ viewport จะตัดขึ้นบรรทัดใหม่เมื่อหน้าต่างแคบ รองรับหน้าต่างขั้นต่ำ 1100×700

ธีมเริ่มต้นเป็น Dark และบันทึกตัวเลือกใน key `appearance` ของ `config/local.json` แยกจากโปรเจกต์ โดยรักษา `resource_safety` และ preference อื่นไว้ ถ้าเขียน preference ไม่ได้ ธีมยังเปลี่ยนได้ใน session นั้นและแสดงข้อความใน console

หลังแก้ source ให้ปิดและเปิดโปรแกรมใหม่เพื่อโหลด UI ใหม่ ฟังก์ชัน inference, contacts และ export ใช้ workflow เดิม ดู [คู่มือ ExMR](models/EXMR.md) และ [คู่มือผู้ใช้](USER_GUIDE.md)

## ภาษาไทย / English

เลือก **ไทย** หรือ **English** ที่มุมขวาบน สลับได้ทันทีและบันทึกใน key `language` ของ `config/local.json` โดยไม่เปลี่ยนค่า appearance/resource_safety หรือโปรเจกต์

แปลเมนู ปุ่ม แท็บ คำแนะนำทั่วไป สถานะ readiness และป้ายใน canvas ส่วนชื่อโมเดล ชื่อไฟล์ ค่าที่ผูกกับการควบคุมกล้องบางรายการ คู่มือ HTML ยาว และ technical logs ยังคงชื่อ/ภาษาต้นฉบับเพื่อให้ตรงกับเครื่องมือและแหล่งดาวน์โหลด

## Model Manager คืออะไร

เป็นรายการไฟล์ที่ประกอบกันเป็นขั้นตอนประมวลผล ไม่ใช่ต้องเลือกใช้ AI เพียงแถวเดียว: YOLO ตรวจคน, OSNet แยกบุคคล, Sapiens2 หาจุดร่างกาย, HaMeR วิเคราะห์มือ และ ExMR สร้างการเคลื่อนไหว ส่วน configuration/mean parameters เป็นข้อมูลประกอบโมเดล

Ready หมายถึงไฟล์พร้อม; Missing หมายถึงยังขาด SAM 3.1 เป็นตัวติดตามคนเสริม ใช้ตัวติดตาม Default ได้โดยยังไม่ติดตั้ง SAM 3.1 และ Download All ข้าม checkpoint เสริมนี้ ไฟล์ที่ต้องลงชื่อเข้าใช้/ยอมรับเงื่อนไขยังต้องดาวน์โหลดแล้ว Import ให้ตรงแถว

## AI ช่วยทำงานอย่างไร

Codex เปิดโปรเจกต์ เลือกเฟรม ดูภาพ PNG และเทียบก่อน–หลังแก้จากผลที่บันทึกไว้ได้ผ่าน MCP ของโปรเจกต์ ดู [คู่มือ Codex MCP](CODEX_MCP.md)

ไฟล์ที่ต้อง provider login/access approval/license acceptance ให้ผู้ใช้จัดการในเว็บของผู้ให้บริการ แล้ว Import ผ่าน Model Manager ปัจจุบันการตรวจจับท่าทางด้วย ExMR ยังต้องไฟล์ manual ตามบันทึกติดตั้ง
